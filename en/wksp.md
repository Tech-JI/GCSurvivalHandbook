# Tech Workshops

**TechGC Technical Department** regularly hosts workshops to help students master essential tools for engineering coursework and software development. All workshop materials are open-sourced under the [GitHub Tech-JI](https://github.com/Tech-JI) organization.

## **Shell / Terminal**

### **Linux Install Party**

A hands-on session guiding you through installing Linux on your laptop (dual-boot or virtual machine), plus an introduction to the Linux desktop environment.

- 📁 [github.com/Tech-JI/Linux-Install-Party](https://github.com/Tech-JI/Linux-Install-Party)

### **Bash Workshop** (2026 Spring)

An introduction to the shell command line, covering essential commands, pipes, redirection, and scripting — so you can work efficiently without relying on the mouse.

- 📁 [github.com/Tech-JI/Bash_wksp_26](https://github.com/Tech-JI/Bash_wksp_26)

### **Arch Linux Workshop**

Install and configure Arch Linux from scratch. Understand how a Linux system is put together — ideal for anyone wanting deeper OS knowledge.

- 📁 [github.com/Tech-JI/arch-wksp](https://github.com/Tech-JI/arch-wksp)

## **Version Control**

### **Git Workshop** (2025 Fall)

Introduction to Git version control, covering basic commands, branching, collaboration workflows, and GitHub usage.

### **Git Workshop** (2026 Summer)

- 📁 [github.com/Tech-JI/git_wksp_26su](https://github.com/Tech-JI/git_wksp_26su)

## **Editors / Writing Tools**

### **Vim Workshop** (2026 Spring)

- 📁 [github.com/Tech-JI/vim-wksp-2026](https://github.com/Tech-JI/vim-wksp-2026)

### **VS Code Workshop** (2025 Fall)

Setting up VS Code, recommended extensions, and productivity tips for an efficient coding workflow.

- 📁 [github.com/Tech-JI/VSCode-Wksp-2025](https://github.com/Tech-JI/VSCode-Wksp-2025)

### **Markdown Workshop**

- 📁 [github.com/Tech-JI/markdown-wksp](https://github.com/Tech-JI/markdown-wksp)
